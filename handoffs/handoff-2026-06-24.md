## The DIAPHRAGM Bug — Full Analysis

### Root cause

`tyger_recon.py:107-110` (root repo, currently unmodified):
```python
binning = user_string.get('binning', 'SIGNAL')
bt = bintype.PNEUMOTACH if (binning == 'PNEUMOTACH' and len(g_raw.ilvbin[bintype.PNEUMOTACH])) \
        else bintype.SIGNAL
print(f'binned dynamic recon with {bt.name} binning...', file=stderr)
g_res.dyn_recon(g, g_raw, g_traj, g_raw.ilvbin[bt], g.usegpu)
```

When `binning == 'DIAPHRAGM'`, the condition `binning == 'PNEUMOTACH'` is False,
so `bt = bintype.SIGNAL`. DIAPHRAGM silently becomes SIGNAL.

**Confirmed in tyger.log:** `[main] binned dynamic recon with SIGNAL binning...`

### Why DIAPHRAGM needs a navigator loop

`g_raw.ilvbin[bintype.DIAPHRAGM]` starts as `[]` (see `raw.py:116`). SIGNAL and
PNEUMOTACH get populated in `load_from_arr()`. DIAPHRAGM is never populated there.

DIAPHRAGM requires a separate navigator reconstruction loop that:
1. Uses a low-res MS (`g.MS = g.IS + 4` = 104 instead of 240)
2. Reconstructs each undersampled spiral interleave group as one low-res image
3. Extracts the diaphragm z-position from the z-dropoff profile (parabola fit)
4. Smooths with Savgol filter → `ilvvol[DIAPHRAGM]` → `ilvbin[DIAPHRAGM]`

This whole path exists in `main.py:279-330` (Steve's GUI code) but was **never
ported to `tyger_recon.py`** (Kento's headless Tyger entrypoint).

### The DIAPHRAGM algorithm (from `main.py:279-330`, copy for reference)

```python
# Called after calcb(), before dyn_recon()
saveMS = g.MS
g.MS = g.IS + 4          # low-res navigator matrix (e.g. 104 for IS=100)
g_res.calcb(g, g_raw, g_traj, True)   # recompute b at low res
nusimg = int(g_raw.ntotalilvs * g_raw.npts / g_traj.nsmpperusimg)
tempvolmeasvol = []
for iusimg in range(nusimg):
    res = g_res.dyn_usimg_recon(g, g_raw, g_traj, g.usegpu, iusimg)
    if not res:
        continue
    dropoff = np.sum(np.abs(g_res.getimg(imgtype.GPDYN)[
                    :, int(g.IS/4):int(3*g.IS/4), :]), (1, 2))  # (IS,) z-profile
    # find 25%-75% transition → fit parabola → midpoint = diaphragm z
    for p1 in range(g.IS - 1, 0, -1):
        if dropoff[p1] > np.min(dropoff) + 0.25*(np.max(dropoff)-np.min(dropoff)):
            break
    for p2 in range(p1, 0, -1):
        if dropoff[p2] > np.min(dropoff) + 0.75*(np.max(dropoff)-np.min(dropoff)):
            break
    if p1 - p2 >= 2:
        p = np.polyfit(np.arange(p2, p1), dropoff[p2:p1], 2)
        det = np.sqrt(p[1]**2 - 4*p[0]*(p[2] - (np.max(dropoff)+np.min(dropoff))/2))
        m1 = (-p[1] + det) / (2*p[0])
        m2 = (-p[1] - det) / (2*p[0])
        ilvperusimg = int(g_traj.nsmpperusimg / g_raw.npts + .1)
        candidate = None
        if m1 > p2 and m1 < p1:
            candidate = m1
        elif m2 > p2 and m2 < p1:
            candidate = m2
        if candidate is not None:
            tempvolmeasvol.append(candidate)
            g_raw.volmeastime[bt].append(np.mean(
                g_raw.ilvtime[iusimg*ilvperusimg:(iusimg+1)*ilvperusimg]))
    if len(g_raw.volmeastime[bt]) > 5:
        ftvol = savgol_filter(tempvolmeasvol, 5, 2)
        minftvol = np.min(ftvol)
        g_raw.ilvvol[bt] = np.interp(g_raw.ilvtime, g_raw.volmeastime[bt],
                (ftvol - minftvol)/(max(ftvol)-minftvol), left=np.nan, right=np.nan)
        g_raw.rescale(g_raw.ilvvol[bt])
        g_raw.ilvbin[bt] = g_raw.bin(g_raw.ilvvol[bt])
# restore MS, then do the binned recon
g.MS = saveMS
g_res.calcb(g, g_raw, g_traj, g.usegpu)   # recompute b at full res
g_res.dyn_recon(g, g_raw, g_traj, g_raw.ilvbin[bt], g.usegpu)
```
