## Verdicts (F96–F98)
1. Soft binning: ranking stable in all 12 runs (F96). Soft-bin width itself not judgeable on a static object.
2. SNR: deapod safe everywhere (0.91–1.006). MS 200 gain reverses below SNR ≈ 9–12 → keep MS 240. Per-SNR LB pays only
   below ≈ 7 (2 sessions) and makes resolution track SNR → one LB for all (F97).
3. Registration: MS 160 worse than MS 200 worse than MS 240 on every proxy at every noise level; proxies rule out
   sharpening, cannot set the smooth end → PCA benchmark (F98).
